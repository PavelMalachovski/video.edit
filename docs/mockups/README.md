Исходники Design-артефакта «Video Edit — макеты» (https://claude.ai/artifact/UfqK2GZKXY7qtWU9JeGjm6,
версия 1791632985-dce3): `Main` — «1 · Загрузка», `Questions` — «2 · Вопросы», `Previews` — «3 · Три превью»,
`Result` — «4 · Готово». Смотреть их удобнее в самом артефакте (файлы ссылаются на его `support.js`); здесь они —
для сверки вёрстки: цвета, размеры, тексты.

Тексты в макетах примерные (дизайн, §4). Где макет расходится с планом 3, страница следует плану:

- «Несколько частей — склею по порядку» — нет: одна задача = один файл (дизайн, §5.2, решение после замеров);
  подсказка под кнопкой называет настоящий предел — 3 ГБ (`checkSource`).
- «я покажу два варианта кадра» и «Показать два превью» — превью три (A, B, C), кнопка — «Показать превью».
- Полоса шагов (Загрузка · Текст · Вопросы · Превью · Монтаж) — и на экране загрузки, и на странице задачи.
