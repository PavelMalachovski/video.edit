# Макет редактора с дорожками (фаза 1)

Кликабельный макет редактора по мотивам veed.io — https://claude.ai/artifact/9LwzYfsaUys1S5rrN5dQPt
(исходник — `editor.html`; это фрагмент страницы: `<!doctype>`, `<head>` и `<body>` добавляет хост артефакта).
Дизайн и план — `docs/superpowers/specs/2026-10-12-editor-and-saas-design.md`.

- Светлый вид, раскладка veed: шапка, рельса инструментов и панель слева, кадр 9:16 по центру, таймлайн внизу
  (Видео, Голос, Музыка, Звуки, Субтитры, Текст, Вставки). Ни логотипа, ни названия veed — своё имя и значок.
- Ролик примерный: два файла (`IMG_4512.MOV` — улица, шумно; `IMG_4520.MOV` — дома), слова с временем, черновик
  автомонтажа (паузы вырезаны). Кадр нарисован, звука нет. В сервисе кадр — настоящее видео (прокси), текст рисует
  `template/`, монтирует движок.
- Работает: пуск, плейхед, зум; разрезать (S), удалить (Delete), вернуть вырезанное (＋ на стыке), перетащить кусок,
  обрезать край с привязкой к словам; громкость и mute дорожек; музыку тянуть и обрезать; звуки и вставки из панелей;
  текст и вставки — тянуть и растягивать; «Очистить голос» (подсказка на дорожке, сила, «до/после»); стиль A/B/C,
  шрифт, цвета; отмена и повтор; ревизии таймлайна; «Монтировать» → v2 и «Скачать»; RU/EN.
- Телефон (уже 860 px): кадр, простой таймлайн (видео и голос), инструменты вкладками; касание куска выделяет его,
  свайп листает таймлайн.
