# assets — файлы Павла для монтажа

Сервис только читает эту папку и никогда её не меняет.

| Папка | Что класть | Как используется |
|---|---|---|
| `logos/` | Логотипы (PNG с прозрачностью или SVG) | Вставки там, где в кадре сказано «добавь сюда …» |
| `library/` | Постоянные вставки на все ролики: скрины, мемы, стикеры, короткие демо-видео | Claude открывает и смотрит каждую и предлагает ту, что прямо подходит к сказанному. Сомнение — не ставит |
| `music/` | Фоновая музыка (mp3) | Вопрос «Музыка» перед монтажом; играет с первого кадра, тише голоса |
| `sfx/` | Короткие звуки появления: свуш, поп (mp3/wav) | Звучат в момент появления каждой вставки |
| `fonts/` | Свои шрифты (ttf/otf) сверх встроенного списка | Появляются в выборе шрифта; файл с `-hand` в имени — рукописный |

Называйте файлы понятно: `скрин-статистики.png`, `мем-кот.jpg`, `lofi-утро.mp3`.
Вставки только для одного ролика сюда класть не нужно — их прикрепляют при загрузке видео.
