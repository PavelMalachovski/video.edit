# Настройка video.edit

Что делает Павел своими аккаунтами (один раз). Всё остальное уже в репозитории.
Порядок важен: шаги 2–4 опираются на код в ветке `master`.

## 1. Код в master
Vercel, рутина и GitHub Action берут код из `master`. Пока разработка идёт в ветке
`ccr-862b766a-c9c3qm` — её нужно слить в `master` (pull request).

## 2. Токен GitHub (для страницы на Vercel)
GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** →
Generate new token:
- Repository access: **Only select repositories** → `video.edit`
- Permissions → Repository permissions → **Contents: Read and write** (создавать черновики
  релизов, загружать и удалять файлы, удалять ветки задач)
- Expiration: 1 год
Скопируйте токен — он понадобится в шаге 3. Никуда больше его не вставляйте.

## 3. Vercel
vercel.com → Add New → Project → Import `PavelMalachovski/video.edit`:
- **Root Directory**: `web`; Framework: Next.js (определится сам).
- Там же, под Root Directory, должна быть включена **Include files outside the root directory in the Build Step**
  (по умолчанию включена): сборка берёт шаблон превью из папки `template/` рядом с `web/`. Если её выключить,
  сборка остановится с подсказкой «template/ не найден рядом с web/…».
- **Environment Variables** (Production):
  - `APP_PASSWORD` — пароль для входа на страницу (придумайте);
  - `SESSION_SECRET` — длинная случайная строка (например, 40 любых символов);
  - `GITHUB_TOKEN` — токен из шага 2;
  - `GITHUB_REPO` = `PavelMalachovski/video.edit`;
  - `ROUTINE_ID`, `ROUTINE_TOKEN` — после шага 4 (потом Redeploy).
  - `ROUTINE_API_URL`, `GITHUB_API_URL`, `GITHUB_UPLOADS_URL` **не задавайте** — они только для проверок с
    поддельным GitHub.
- Deploy. Адрес вида `https://video-edit-….vercel.app` — это и есть страница.

## 4. Облачное окружение и рутина Claude
claude.ai/code:
1. **Окружение** (меню облачного окружения → New/Edit): имя `video-edit`; сеть — по
   умолчанию (Trusted); **Setup script** — вставьте целиком содержимое
   `setup/cloud-setup.sh` из репозитория. Он ставит распознавание речи и проверяет ffmpeg;
   первый раз ~1,5 минуты, дальше кэшируется.
2. **Рутина** (Routines): рутина `video-edit` уже создана для проверки — откройте её и **замените промпт** текстом
   из `setup/routine-prompt.md` (между линиями). Если её нет — New: имя `video-edit`, репозиторий `video.edit`,
   окружение `video-edit`, тот же промпт, расписание не нужно, **API-триггер включён**. Модель — по умолчанию.
3. Id рутины и токен API-триггера — в Vercel (`ROUTINE_ID`, `ROUTINE_TOKEN`), затем Redeploy. Если они уже стоят
   с проверки — ничего не меняйте.
   - **Id** — вида `trig_…`: в адресе страницы рутины на claude.ai/code (Routines → video-edit) или в её настройках.
   - **Токен** — вида `sk-ant-oat01-…`: показывается один раз, когда включаете API-триггер. Не сохранили —
     в настройках API-триггера рутины выпустите новый (старый перестанет работать) и скопируйте сразу.
   - Vercel → проект → Settings → Environment Variables → Add: `ROUTINE_ID` и `ROUTINE_TOKEN` (Environment:
     Production). Переменные действуют только на **новых** сборках: Deployments → последняя → ⋯ → **Redeploy**.
   - Страница пишет «Сервис не настроен: в Vercel нет переменной …» — значит, этой переменной нет или не было
     Redeploy после неё.

## 5. Проверка всего пути с iPhone (Safari)
Не открывая чат с Claude:
1. Откройте страницу, войдите паролем.
2. «Выбрать видео» → реальный ролик на 1–2 минуты из «Фото» (как снимает телефон, HDR). В «ТЗ» — коротко: хук
   («ХУК: …») и одна вставка («когда говорю X — покажи Y»), к ней — картинка через «Вставки для этого ролика».
   «Загрузить» — дождитесь, пока откроется страница задачи.
3. Смотрите фазы: «Запускаю сессию» → «Скачиваю видео» → «Расшифровываю» → … → «Ждёт ответов».
4. Ответьте на вопросы: для «добавь сюда» выберите логотип из `assets/`, трек из `assets/music/` → «Показать
   превью».
5. Выберите вариант, шрифт, рукописный шрифт и цвета → «Монтировать: …».
6. Получите ролик: субтитры, хук, шкала и вставки — как на выбранном превью; речь чуть быстрее, без длинных пауз;
   зумы по смыслу; музыка под голосом и звуки появления вставок; цвета кожи естественные.
7. «Поправить» → например, «логотип чуть левее» → «Переделать» → получите исправленный ролик (версия 2).
Напишите в чат, что видели — особенно ошибки и места, где превью разошлось с роликом.
