# video.edit на любом языке — дизайн (этап 1: латиница и кириллица)

Дополнение к `2026-10-10-video-edit-service-design.md` (дальше — «основной дизайн»). Где они расходятся, прав этот
документ: он отменяет решение №14 основного дизайна («речь только русская») и строки §6 и §5 о русском языке.

## 1. Зачем

Павел снимает ролики не только по-русски: ролик может быть целиком на любом языке и для любой аудитории. Сейчас сервис
понимает только русскую речь — распознавание GigaAM знает только русский, Whisper жёстко настроен на `ru`, правила
монтажа (звёздочки по русским корням, «э-э», «м-м») и шрифты рассчитаны на кириллицу. Ролик на английском или чешском
сегодня выйдет с субтитрами-кашей.

## 2. Цели, не-цели, анти-цели

**Цели (этап 1)**
- Ролик целиком на языке, который пишется латиницей или кириллицей и разделяет слова пробелами (английский, чешский,
  немецкий, испанский, французский, польский, украинский, сербский и т. д.), монтируется так же, как русский: вопросы,
  три превью, ролик, «Поправить».
- Субтитры — на языке речи, с точным временем слов: подсветка слова в karaoke попадает не хуже русской (±0,1 с).
- Хук, титр с кодовым словом и кодовое слово — на языке ролика.
- Звёздочки, вырезка оговорок и слов-паразитов работают на языке ролика.
- Шрифт в ролике и на превью всегда содержит все буквы текста.

**Не-цели**
- Перевод: субтитры только на языке речи, без перевода и второй строки.
- Смешанная речь в одном ролике (русский с чешскими фразами) — не цель этапа 1; ролик считается одноязычным.
- Интерфейс страницы и вопросы Claude остаются для Павла на русском.
- Этап 2 — отдельно и позже: греческий, арабский и иврит, китайский, японский, корейский, хинди, тайский (свои
  шрифты, письмо справа налево, письмо без пробелов между словами).

**Анти-цели**
- Русский ролик монтируется хуже или медленнее, чем сейчас (GigaAM остаётся для русского).
- Буквы, которых нет в шрифте, тихо подменяются другим шрифтом (превью ≠ финал) или выходят квадратиками.
- Язык угадан неверно, и об этом никто не узнал: неуверенность — вопрос Павлу, а не молчаливая каша.
- Ролик на неподдержанной письменности (этап 2) монтируется «как получится» — вместо этого понятная ошибка.

## 3. Решения Павла

1. Ролик может быть на любом языке для любой аудитории.
2. Субтитры — как говорят, на языке речи, без перевода.
3. Сначала латиница и кириллица; остальные письменности — вторым этапом.
4. Принял описание целиком (язык определяется сам; «ЯЗЫК:» в ТЗ; русский остаётся на GigaAM; хук и кодовое слово —
   на языке ролика; вопросы — по-русски; звёздочки по языку ролика; проверка шрифтов).

## 4. Как это выглядит для Павла

- Загрузка — как сейчас. В ТЗ можно написать `ЯЗЫК: чешский` (или `ЯЗЫК: cs`); не написал — язык определяется по речи.
- Страница задачи: в фазе «Расшифровываю» видно язык («Расшифровываю (чешский)»).
- Вопросы — по-русски, но варианты хука, кодового слова, написания слов и звёздочек — на языке ролика. Если язык
  определился неуверенно, первый вопрос — «На каком языке ролик?» с вариантами.
- Превью: в выборе шрифта только шрифты, в которых есть все буквы этого ролика; остальные не показываются (или
  показываются выключенными с пометкой «нет букв ř, ů» — на выбор строителя).
- Ролик на неподдержанной письменности: красная карточка «Язык <имя> пока не поддерживается (этап 2)».

## 5. Устройство

### 5.1 Язык ролика
- Источник правды — один файл в папке задачи (имя и форма — строителю), который пишет `vm prepare`: код языка
  ISO 639-1, его название по-русски, уверенность, откуда взят (`brief` | `detected` | `answer`).
- Порядок: `ЯЗЫК:` из ТЗ → определение по речи (Whisper умеет определять язык) → при низкой уверенности —
  вопрос Павлу на шаге analyze, ответ записывается туда же и шаг render берёт его.
- Определён язык этапа 2 — шаг заканчивается статусом ошибки с понятным текстом.

### 5.2 Распознавание и время слов
- Русский — как сейчас: GigaAM (время слов) + Whisper (`ru`, сплошной текст с пунктуацией).
- Остальные языки этапа 1 — новый путь, который даёт и текст, и время каждого слова. Кандидаты (выбор — по замеру,
  см. §7):
  - **NeMo Parakeet TDT 0.6B v3** в sherpa-onnx (`sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8`, ~490 МБ, лежит в
    релизах k2-fsa/sherpa-onnx на GitHub — оттуда облако качает модели): 25 европейских языков (en, cs, de, es, fr,
    it, pl, pt, uk, ru и др.), отдаёт время токенов — первый кандидат;
  - Whisper (тот же turbo, язык из §5.1) для сплошного текста с пунктуацией — как reference, как сейчас для русского;
  - для языков вне списка модели — запасной путь (например, текст Whisper, разложенный по речи VAD с пометкой о
    неточном времени, или выравнивание другой моделью) — решает строитель по замеру; такой ролик честно получает
    предупреждение в сводке `prepare` и в `result.json`.
- Модели ставит `setup/cloud-setup.sh` (кэш облачного окружения); всё, что не нужно для русского, не должно
  замедлять русский ролик.
- Выход для остальной цепочки не меняется: `words.json` (слова с временем), `reference.txt`, `speech.json` — резка,
  субтитры, SRT и превью работают без изменений.

### 5.3 Правила монтажа (SKILL.md)
- Часть 1 «Правила»: «Речь только русская» → «Речь — на языке ролика (§5.1); субтитры на нём же».
- Звёздочки: для русского — нынешние корни; для других языков Claude сам находит «денежные» и рискованные для
  алгоритмов слова этого языка (деньги, бесплатно, цена, подписка, заработок и т. п.) и ставит `*` по тому же
  принципу (одна гласная в середине); список — вопрос `stars`, как сейчас.
- Вырезка оговорок и слов-паразитов — по языку («um», «uh», «ehm», «no jo» и т. п.).
- Хук, титр, кодовое слово, стикеры — на языке ролика; вопросы, `body`, объяснения в `result.json` — по-русски
  для Павла.
- Правила, где сейчас прямо написан русский (капс хука, «последнее слово рукописным»), остаются: они не зависят от
  языка.

### 5.4 Шрифты
- Покрытие букв — свойство шрифта. Движок проверяет на `vm check`/`vm render`, что выбранный основной и рукописный
  шрифты содержат все символы текста ролика (субтитры, хук, титр, стикеры); нет — проблема с перечнем букв и
  подсказкой, какие шрифты подходят. Тихой подмены нет.
- Стили (`styles.json`) Claude собирает только из шрифтов, покрывающих текст ролика.
- Страница показывает в выборе шрифта только подходящие (или выключенными с пометкой) — по тем же данным
  покрытия. Откуда страница берёт данные покрытия и множество букв ролика — строителю (например, покрытие
  считается при сборке в `fonts.json`, а буквы ролика лежат в `styles.json`).
- Встроенные шрифты (проверено): все покрывают латиницу с диакритикой (чешский, польский, немецкий, французский,
  турецкий) и кириллицу с украинскими буквами; вьетнамский — только Montserrat, Unbounded, Oswald, Comfortaa, Rubik;
  греческий — только Comfortaa.

### 5.5 Страница
- Тексты интерфейса не меняются (русский).
- Фаза анализа может показывать язык; вопрос о языке — обычный `choice`.
- Фильтр шрифтов на превью (§5.4).
- Неподдержанный язык — обычная карточка ошибки (статус от сессии).

## 6. Ограничения
- Облако: модели только с GitHub-релизов (huggingface.co закрыт), диск сессии ограничен, 4 vCPU / 16 ГБ.
- Время шага analyze не должно заметно вырасти для русского ролика; для другого языка — укладываться в пороги «завис»
  страницы (25 мин на фазу, растут с длиной ролика).
- Договор о файлах страница ↔ сессия меняется только совместимо (новые необязательные поля/файлы).

## 7. Что оставлено строителю
- Выбор пути времени слов для нерусских языков — по замеру: короткий спайк на английском и чешском образцах
  (речь из espeak/реальные записи), точность начала слов против эталона, скорость на 4–5-минутном ролике, память.
  Порог: начало слова ±0,1 с в 90 % слов.
- Имя и форма файла языка; как Whisper определяет язык в sherpa-onnx и как мерить уверенность.
- Список языков этапа 1 = языки выбранной модели (плюс запасной путь); точная граница — по замеру.
- Механика проверки покрытия шрифтов (fontTools в движке; покрытие для страницы).
- Фикстуры для тестов на других языках.

## 8. Как поймём, что готово
- Английский и чешский ролики (короткие фикстуры и хотя бы один реальный) проходят analyze → render: субтитры на языке
  речи, подсветка слова ±0,1 с, хук и кодовое слово на языке ролика, звёздочки предложены на языке ролика.
- Русский ролик монтируется как раньше (те же тесты, время шага не выросло заметно).
- Текст с буквами, которых нет в шрифте, не проходит `vm check`; на превью такой шрифт не предлагается.
- Ролик на неподдержанной письменности получает понятную ошибку.
- `ЯЗЫК:` в ТЗ побеждает определение; неуверенное определение превращается в вопрос.

## 9. Что решил строитель

Работа шла без отдельного плана (Павел попросил без процессов superpowers): сразу код через тесты.

- **Время слов.** Замер — `docs/spikes/2026-10-results.md`, «Другие языки». Whisper turbo из релиза времени слов не
  даёт (экспорт без cross-attention). Parakeet TDT v3 на живой речи совпал с GigaAM: 92 % начал слов ближе 0,1 с,
  в среднем 42 мс. Поэтому: русский — GigaAM, 24 языка Parakeet (кроме греческого) — Parakeet тем же путём (куски
  15–60 с, перераспознавание по фразам), прочие языки этапа 1 — текст Whisper по фразам VAD с временем по буквам и
  предупреждением в сводке. Цена ошибки: для сербского, турецкого, вьетнамского и т. п. подсветка слова неточная.
- **Язык.** `engine/vm/lang.py`; файл `language.json` (схема в `engine/vm/schemas/`). Без «ЯЗЫК:» Whisper идёт без
  языка — язык определяет каждое окно записи (даром: те же окна, что для текста), окна не того языка слушаются
  ещё раз на языке большинства. «Не уверен» = окна разошлись или Whisper нет. Сначала решает Claude по тексту
  (`vm prepare --lang`), вопрос `language` — только если сам не понял. Цена: на русском ролике без «ЯЗЫК:» до
  нескольких окон Whisper заново, если какое-то окно услышало другой язык.
- **Шрифты.** `engine/vm/fonts.py`: таблица символов шрифта (fontTools — новая зависимость, ставит
  `cloud-setup.sh`), буквы текста и его капс. `vm check`/`vm render` останавливаются до рендера; `vm fonts` даёт
  списки для `styles.json.fonts`, страница (`allowedFonts`) показывает только их и не берёт из памяти выбор со
  шрифтом без букв. Поля нет — все шрифты (старые задачи). Проверено: в Russo One и Marck Script нет румынской «ț»,
  вьетнамских букв нет в Rubik, Russo One, Caveat, Marck Script, казахских — в Unbounded, Russo One, Marck Script.
- **Страница** язык отдельно не показывает: фаза «Расшифровываю» пишет его в тексте статуса («Язык — чешский: …»).
- **Модели.** `cloud-setup.sh` ставит Parakeet по умолчанию (~490 МБ, параллельно с остальными); `VM_PARAKEET=0` —
  без него.

### Ревью всей работы (свежий агент) и что исправлено
Критичных нет. Исправлено (каждое — с тестом):
- Соседние языки (ru/uk/be, bg/mk, sr/hr/bs, cs/sk, no/da/sv, id/ms): Whisper может ошибиться во всех окнах сразу,
  а ролик до 28 с — одно окно. Сводка теперь всегда просит проверить язык «по речи» и называет соседей; SKILL
  велит проверять всегда, не только при «не ясен».
- `vm fonts` берёт текст из черновика `edit.json` и вариантов хука/написаний (сырые слова бывают с ♪ и лишней
  греческой буквой); пустой список не остаётся пустым (все шрифты + предупреждение), страница пустой список тоже
  считает «все».
- Невидимые символы (U+200B, U+200D, U+FE0F, мягкий перенос, оттенки кожи) букв не требуют; эмодзи — отдельная
  проблема `vm check` с выходом «убери и скажи в unsure» (в SKILL). С 11.10.2026 эмодзи из набора рисуются
  картинками и букв не требуют (дизайн по гайду Reels, § 3.1); проблема — только символы без картинки и эмодзи в
  субтитрах.
- Ирландский убран: Whisper его не знает, sherpa-onnx завершал процесс. Тест сверяет языки без Parakeet со списком
  Whisper. `nn`/`nb` → норвежский; редкий код Whisper уступает известному («не уверен»).
- `--lang` с тем же языком записывает ответ; `--redo` не теряет ответ Павла; старая задача без `language.json` —
  русская, `--lang ru` её заново не распознаёт; голоса окон не пишутся, когда язык задан.
- Whisper-путь: поля фразы не больше половины паузы до соседней, обрывки VAD короче 0,3 с не слушаются.
- Токены Parakeet без букв («▁¿», «▁-», «▁.») липнут к слову, а не становятся словами.
- `ЯЗЫК:` с пустым значением не берёт следующую строку; `pt-BR`, `uk_UA` понимаются; длинная фраза после
  «Язык:» (больше 3 слов) — не язык ролика.

Отложено (мелочи):
- Турецкий и азербайджанский капс хука: шаблон пишет `toLocaleUpperCase('ru-RU')`, а там нужна «İ»; `glue` знает
  только русские и латинские короткие слова.
- Whisper-путь: зацикливание на обрывке («yellow yellow yellow»), без VAD мягкая резка не находит пауз, на 4–5-минутном
  ролике ~80–100 фраз — 3–5 мин; нет сверки покрытия речи словами для этого пути.
- Русский без GigaAM, но с Parakeet — отказ (Parakeet русский умеет, можно было бы взять его).
- `SPARSE` (1,5 слова/с) чаще срабатывает на языках с длинными словами (fi, hu, de) — только время.
- Рукописный список `vm fonts` проверяется с запасом по всему тексту черновика.
- `language.json` — без TS-типа: страница его не читает.
