# Проверка редактора на настоящем ролике (12.10.2026)

Страница — `../real.html` (артефакт https://claude.ai/artifact/LfL8J3YthYmYRUJ3UmsPa8, приватный: в нём лицо и голос
героини ролика). Ролик — первые 30 с исходника задачи `261012-091256-w7eu` (`IMG_8524 (2).MOV`, 4K HEVC с iPhone).
Медиафайлы в git не кладём: их делает `prep_media.py`, публикуются рядом со страницей.

1. `vm fetch` задачи рутины → `ffmpeg -t 30 -c copy` → тестовая задача (слова, речь, нарезка — из задачи рутины,
   обрезанные до 30 с) → `vm prepare` (нормализация 1080×1920, 43 с; распознавание пропущено — слова уже есть).
2. `prep_media.py`: прокси 540×960 (H.264, ключевой кадр каждые 0,5 с), голос 48 кГц → DPDFNet2-48k (RTF 0,28),
   `voice-pair.mp4` (слева исходный, справа очищенный — одним плеером, без рассинхрона), волна, лента кадров,
   музыка рутины, `data.json` (нарезка, слова, хук, акценты, зумы, ч/б, стиль, уровни).
3. Страница по «Монтировать» пишет таймлайн в своё хранилище (`renders/<id>`); Claude читает его,
   `render_timeline.py` делает `edit.json` тестовой задачи (очистка голоса — смешанный голос вместо дорожки
   source.mp4, как в дизайне) → `vm validate` → `vm render` → копию для просмотра кладёт в артефакт.
