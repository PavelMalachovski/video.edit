# video.edit

Сервис монтажа коротких вертикальных видео: заливаешь видео с телефона на страницу,
отвечаешь на вопросы, выбираешь стиль по превью — Claude (облачная сессия по
подписке) монтирует.

- Дизайн: `docs/superpowers/specs/2026-10-10-video-edit-service-design.md`
- Планы: `docs/superpowers/plans/`
- Результаты проверок: `docs/spikes/2026-10-results.md`
- Файлы для монтажа (логотипы, музыка, вставки): `assets/` — см. `assets/README.md`
- Подготовка облачной сессии: `bash setup/cloud-setup.sh`
