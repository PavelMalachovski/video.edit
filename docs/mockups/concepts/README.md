# Концепты дизайна страницы

Пять вариантов в духе veed.io и похожих редакторов — исходники Design-артефакта «video.edit — 5 концептов дизайна»
(https://claude.ai/artifact/76QYRyh42Z9nmUEhWWo25Z). Смотреть удобнее в самом артефакте (файлы ссылаются на его
`support.js`); здесь они — для сверки вёрстки. У каждого концепта три экрана: «Загрузка», «Выбери стиль», «Готово»;
акцентный цвет каждого экрана меняется в Tweaks.

| № | Концепт | По мотивам | Файлы |
|---|---|---|---|
| 1 | Студия: светлый фон, крупный чёрный шрифт (Onest), чёрные кнопки-таблетки, лаймовый маркер на главных словах | VEED | `Main`, `Studio-*` |
| 2 | Монтажка: тёмный редактор (Geologica, тайм-коды — JetBrains Mono), бирюзовый акцент, превью сверху, настройки во вкладках | CapCut | `Cut-*` |
| 3 | Неон: тёмно-фиолетовый, заголовки как субтитры (Unbounded, Golos Text), кислотный акцент, свечение | Submagic, Opus Clip | `Neon-*` |
| 4 | Текст: светлый «документ» (IBM Plex Sans и Mono), расшифровка с подсветкой, правки как комментарии | Descript | `Text-*` |
| 5 | Конструктор: светло-сиреневый, цветные плитки, крупные скругления, нижнее меню (Rubik) | Canva, Kapwing | `Kit-*` |

**Выбран второй — «Монтажка»** (11.10.2026): по нему сделана страница, дизайн —
`docs/superpowers/specs/2026-10-11-montazhka-design.md`.

Это не копии чужих продуктов: ни логотипов, ни их шрифтов — только общее направление. Тексты и цифры на экранах
примерные. Кадр на превью и жёлтая подсветка субтитров — содержимое ролика (его рисует `template/`), поэтому во всех
концептах они одинаковые.
